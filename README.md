# N2 冲刺自习室

面向近期参加 JLPT N2 的学习页面。未登录时记录保存在本机；接入云端服务后，可用学习账号在不同设备之间同步。部署步骤见 [DEPLOY.md](DEPLOY.md)。

## 打开

在文件管理器中直接打开 `index.html`。未登录时，答题统计、错题和每日任务保存在当前浏览器。通过 HTTPS 首次打开后，离线缓存可让页面继续练习；云端登录和同步需要网络。

页面不加载在线字体、远程图片或外部题库。题目和例句为原创训练内容，不是官方真题。听力部分目前以对话文字训练理解，不含录音；暂未实现真实整套计时模考、JLPT 换算分数或完整题库。

## 当前功能

- 默认 N2，可切换 N1–N5；提供词汇、语法、阅读和听力文本练习
- 原创练习题答题后显示中文解析，错题加入复习
- 20 分钟专注计时、每日 60 分钟计划和考试倒计时
- 未登录时在本机浏览器保存进度
- 配置云端 API 后可用 leo1–leo5 登录，同一账号在设备间同步
- 适配桌面和手机屏幕

跨设备账号需要额外部署 Cloudflare Worker 与 D1 数据库，设置方法见 [backend/README.md](backend/README.md)。五个账号共用同一密码时，知道密码的人都能进入任一账号并查看或修改该账号的学习记录。不要在账号中保存隐私信息。

## 数据位置

未登录时数据保存在当前浏览器的本机存储中，不会上传。登录后，学习记录才会同步到所配置的云端服务。清除浏览器数据或换浏览器会清除本机缓存，但已同步的数据仍在云端。
