# N2 冲刺自习室

面向近期参加 JLPT N2 的学习页面，可直接部署到 GitHub Pages。学习记录按 leo1–leo5 分开存储，并通过 MantleDB 免费匿名 JSON 服务在设备间同步，无需注册或密码。

## 当前功能

- 默认 N2，可切换 N1–N5；提供词汇、语法、阅读和听力文本练习
- 原创练习题答题后显示中文解析，错题加入复习
- 20 分钟专注计时、每日学习计划和考试倒计时
- 五个学习账号分别记录答题、错题、每日计划和考试日期
- 学习变更后自动上传；页面打开时及每 30 秒检查其他设备的新记录
- 适配桌面和手机屏幕

## 数据与限制

云端数据存放在无注册的公开 MantleDB namespace 中。它无需账号，免费层每个 namespace 最多 100 条记录、每条 64 KB、每日 10,000 次请求；连续 30 天没有写入时会清理 namespace。当前每个学习账号保存一条 JSON 记录。任何知道网站和账号名的人都能读写对应进度，不能用于隐私数据。学习记录也会发送至 MantleDB 服务。

云端暂时不可用时，答题和计划仍保存在当前浏览器；恢复连接后可用相同账号重新同步。题目和例句为原创训练内容，不是官方真题。听力部分目前以对话文字训练理解，不含录音；暂未实现完整计时模考或 JLPT 换算分数。
