# N2 冲刺自习室

面向近期参加 JLPT N2 的学习页面。学习账号仅用于区分本机记录，不设密码、不上传数据，也不支持跨设备同步。部署步骤见 [DEPLOY.md](DEPLOY.md)。

## 打开

在文件管理器中直接打开 `index.html`。答题统计、错题和每日任务按 leo1–leo5 分别保存在当前浏览器。通过 HTTPS 首次打开后，离线缓存可让页面继续练习。

页面不加载在线字体、远程图片或外部题库。题目和例句为原创训练内容，不是官方真题。听力部分目前以对话文字训练理解，不含录音；暂未实现真实整套计时模考、JLPT 换算分数或完整题库。

## 当前功能

- 默认 N2，可切换 N1–N5；提供词汇、语法、阅读和听力文本练习
- 原创练习题答题后显示中文解析，错题加入复习
- 20 分钟专注计时、每日 60 分钟计划和考试倒计时
- leo1–leo5 五个学习账号可切换，各自进度保存在本机浏览器
- 账号不设密码；切换账号只切换本机记录空间
- 适配桌面和手机屏幕

## 数据位置

五个账号的数据分别保存在当前浏览器本机存储中，不会上传。换设备、换浏览器或清除浏览器数据后，记录不会自动转移。
