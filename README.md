# N2 冲刺自习室

面向近期参加 JLPT N2 的本地优先学习页面。无需安装依赖、登录账号或连接题库网站。也可直接部署到静态托管平台，步骤见 [DEPLOY.md](DEPLOY.md)。

## 打开

在文件管理器中直接打开 `index.html`。首次使用建议在同一个浏览器中固定打开这份文件；学习统计、错题和每日任务保存在该浏览器本机存储中。清除浏览器数据或换浏览器会清除/无法看到这份记录。

页面代码不加载在线字体、外部脚本、远程图片或外部题库。通过 HTTPS 首次打开后，离线缓存可让页面继续打开和练习；也可以直接用 `file://` 本机打开（此模式不会启用 PWA 缓存）。

## 当前功能

- 默认 N2，可切换 N1–N5；N2 提供词汇、语法、阅读和听力文本练习
- N2 原创练习 30 题，覆盖词汇、语法、阅读和听力文本，答题后显示中文解析
- 错题自动加入本地错题回顾
- 20 分钟专注计时
- 可编辑考试日期，并显示剩余天数（默认 2026-12-06）
- 每日 60 分钟任务清单、已完成题数和正确率统计
- 本地浏览器保存进度，不需要账号或服务器
- 适配桌面和手机屏幕

题目和例句均为原创训练内容，不是官方真题。听力部分目前以对话文字训练理解，不含录音；暂未实现真实整套计时模考、JLPT 换算分数、账号同步或完整题库。页面没有整合未获授权的网络题库。

## 数据位置

答题统计、错题及当天任务保存在当前浏览器的本机存储中，不会上传。直接以 `file://` 打开时，本地存储行为由浏览器决定；如该浏览器限制本地文件存储，请用本机静态文件服务器打开此目录。
