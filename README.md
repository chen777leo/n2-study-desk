# N2 冲刺自习室

面向近期参加 JLPT N2 的学习页面。学习记录按 leo1–leo5 分账号保存；部署云端 API 后，同一账号可在不同设备间同步。部署说明见 [DEPLOY.md](DEPLOY.md)。

## 当前功能

- 默认 N2，可切换 N1–N5；提供词汇、语法、阅读和听力文本练习
- 原创练习题答题后显示中文解析，错题加入复习
- 20 分钟专注计时、每日 60 分钟计划和考试倒计时
- 五个学习账号分别记录答题、错题、每日计划和考试日期
- 云端 API 配置后自动上传修改，并每 5 秒读取其他设备的新记录
- 适配桌面和手机屏幕

## 数据和账号

云端服务未配置时，记录只保存在当前浏览器。配置 Cloudflare Worker 与 D1 后，数据保存在云端并按用户名隔离。账号不设密码，因此任何知道账号名的人都可以查看或修改该账号记录；不要存放隐私数据。题目和例句为原创训练内容，不是官方真题。听力部分目前以对话文字训练理解，不含录音；暂未实现完整计时模考或 JLPT 换算分数。
